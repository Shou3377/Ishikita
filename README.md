### 週間通知

Bot稼働中、毎週土曜24時（日曜0時・日本時間）を過ぎた最初のチェックで、
`CHANNEL_ID` に登録ユーザー全員の週間獲得ポイントを送信します（チェック間隔1分）。
対象は直前の日曜0時以上、今回の日曜0時未満に初めてACした問題です。
通知作成時のdifficultyを合計し、diff未設定の問題は0点とします。
再ACや過去の問題のdifficulty変更は、新規獲得として数えません。

初回は既存ユーザーの提出履歴を再取得するため、通知まで時間がかかる場合があります。
起動時にも直近の終了済み週を確認し、未通知なら送信します。
通知済みの週はDBに保存します。送信直後・記録直前にプロセスが停止した場合は、
再送される可能性があります。API取得や送信の失敗は次のチェックで再試行します。
Bot停止中の定刻送信はできないため、常時起動しておいてください。

検証: `python -m unittest test_weekly -v`
